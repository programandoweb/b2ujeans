## Criterio de investigación
- La web de B2U define identidad, categorías y contexto comercial.
- Las fuentes externas se usan para detectar tendencias, lenguaje, siluetas, combinaciones y temas editoriales.
- Una tendencia externa no debe atribuirse a B2U como producto disponible si no existe evidencia en el catálogo.
- El post debe conectar la investigación con el universo real de B2U sin inventar inventario.
